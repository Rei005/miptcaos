# Автоматический поиск исходников и генерация зависимостей

## 📝 Условие
В проекте может быть много `.cpp` файлов.

Напишите `Makefile`, который:
1. Автоматически находит все файлы `.cpp` в текущей директории с помощью функции `wildcard`.
2. Формирует список объектных файлов в переменной `OBJS` с помощью функции `patsubst` (файлы `.o` должны складываться в папку `obj/`).
3. Для того чтобы изменение заголовочных файлов автоматически приводило к пересборке нужных модулей без явного указания `calc.h` в правилах, добавляет флаг `-MMD` (или `-MMD -MP`) в `CXXFLAGS` и подключает сгенерированные `.d` файлы с помощью директивы `-include`.
4. Собирает конечный исполняемый файл `calculator` в корне задачи (`.`).
5. Содержит псевдоцель `.PHONY` с целями `all` и `clean`.

## ⚙️ Быстрая сборка и тесты
```bash
make                                  # собрать программу
./calculator                          # запустить
pytest tests                          # запустить тесты
```

## 🧹 Очистка
```bash
make clean
```

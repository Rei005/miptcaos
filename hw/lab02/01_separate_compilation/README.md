# Раздельная сборка с директорией для объектных файлов

## 📝 Условие
Исходный код проекта (`main.cpp`, `calc.cpp`, `calc.h`) находится в этой директории.

Напишите `Makefile`, который:
1. Компилирует исходные файлы и складывает промежуточные `.o` файлы в отдельную папку `obj/` (папка должна создаваться автоматически, если её нет).
2. Собирает конечный исполняемый файл `calculator` в корневой папке задачи (`.`).
3. Содержит псевдоцель `.PHONY` с целями `all` и `clean`.

## ℹ️ Примечание
Исполняемый файл `calculator` должен создаваться именно в корне текущей директории задачи, а все промежуточные объектные файлы — внутри папки `obj/`!

## ⚙️ Быстрая сборка и тесты
```bash
cd 01_separate_compilation
make                                  # собрать программу
./calculator                          # запустить
pytest tests                          # запустить тесты
```

## 🧹 Очистка
```bash
make clean
```

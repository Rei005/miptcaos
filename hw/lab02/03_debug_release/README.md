# Поддержка конфигураций Debug и Release

## 📝 Условие
Напишите `Makefile`, который поддерживает сборку проекта в двух режимах:
* **Release** (по умолчанию): используются флаги оптимизации `-O3`.
* **Debug**: используются флаги отладки `-g -O0`.

Выбор режима осуществляется через передачу переменной `MODE` при запуске `make` (например, `make MODE=debug` или `make MODE=release`). Режим по умолчанию — `release`.

При сборке в разных режимах исполняемые файлы и/или объектные файлы должны собираться с соответствующими флагами компилятора.

## ⚙️ Быстрая сборка и тесты
```bash
make                                  # сборка в режиме Release (по умолчанию)
make MODE=debug                       # сборка в режиме Debug
pytest tests                          # запустить тесты
```

## 🧹 Очистка
```bash
make clean
```
